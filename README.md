# Hola, soy Paola 👋🏽

## Sobre mí 🙋🏽‍♀️
Soy **diseñadora UX/UI y VX (Visitor Experience)**: diseño experiencias centradas en las personas, en pantallas y en espacios físicos, con foco en la usabilidad y la accesibilidad, y llevo cada idea a un prototipo que se puede probar.

Gracias a mi formación previa en desarrollo full stack (React, JavaScript, Java y Spring Boot), entiendo cómo se construye lo que diseño y hablo el mismo idioma que los equipos técnicos. Aporto una mirada que une diseño y desarrollo.
